1.7 远程连接问题与解决

错误 1130：Host not allowed

  • 现象：ERROR 1130 (HY000): Host '192.168.5.11' is not allowed to connect
  • 原因：root 用户默认只允许 localhost。
  • 解决：使用 zzc 用户（已允许 %），或修改 root 的 host 为 %（不推荐）。

错误 2026：SSL connection error

  • 现象：ERROR 2026 (HY000): SSL connection error: unknown error number
  • 原因：MySQL 8.0 默认要求 SSL，但 Windows 客户端版本较低（5.7.21）无法协商。
  • 解决：连接时添加 --ssl-mode=DISABLED。

错误 2059：认证插件不支持

  • 现象：Authentication plugin 'caching_sha2_password' cannot be loaded
  • 原因：MySQL 8.0 默认使用 caching_sha2_password，但客户端 5.7.21 只支持 mysql_native_password。
  • 解决：在服务器端修改用户认证插件：

第二部分：Windows 免安装版（与 MySQL 5.7 共存）

返回目录

2.1 安装前的准备与核心原则

为什么要装第二个 MySQL？ 你已经有一个 MySQL 5.7（端口 3306，服务名 MySQL57），需要再装一个 MySQL 8.0 用于学习或新项目。

核心原则：隔离性 —— 两个版本的服务名、端口、安装目录、配置文件、数据目录必须完全独立，否则会冲突。

下载与解压：

  • 从 MySQL 官网下载 mysql-8.0.46-winx64.zip（免安装版）。
  • 解压到无中文、无空格的路径，例如 D:\DevelopedTools\mysql-8.0.46-winx64。
  • 坑 1：不要解压到桌面或含中文的路径，会导致后续服务启动失败。

2.2 配置文件 my.ini（最关键的环节）

文件位置与命名 —— 在 MySQL 8.0 的解压根目录下新建 my.ini 文件（不是 my-default.ini，也不是 my.cnf）。

2.5 登录与修改密码

登录：

  • 坑 7：-P 是大写字母 P（端口），-p 是小写字母 p（密码）。
  • 坑 8：密码输入时不会显示任何字符（包括星号），这是正常的安全机制。

修改密码：

  • 坑 9：MySQL 8.0 默认密码策略要求包含大小写、数字和特殊字符（如 Root@12345）。
  • 坑 10：如果报错 ERROR 1396，说明用户不存在或主机不匹配，先查 SELECT user, host FROM mysql.user;。

2.7 双版本共存管理

安装目录 D:\...\mysql-5.7.21-winx64 D:\...\mysql-8.0.46-winx64
服务名 MySQL57 MySQL80
端口 3306 13306
配置文件 各自的 my.ini 各自的 my.ini
数据目录 各自的 data 各自的 data
启动/停止 net start/stop MySQL57 net start/stop MySQL80
连接命令 mysql -P 3306 -u root -p mysql -P 13306 -u root -p

坑 15：环境变量 PATH 中不要同时加两个 MySQL 的 bin 目录，否则命令行 mysql 命令会混乱。建议只加常用的那个，另一个用绝对路径调用。

2.8 总结与建议

最佳实践

  1. 配置文件：每次修改 my.ini 后，务必检查编码（ANSI）和路径格式。

  2. 服务管理：注册服务时一定要带 --defaults-file，否则可能读到错误的配置文件。

  3. 密码策略：开发环境可以降低密码强度：

  4. 工具选择：推荐 DBeaver CE（免费、跨平台、支持 MySQL 8.0 新特性）。

你踩过的所有坑一览

  1. 配置文件编码不是 ANSI → 服务启动 3534
  2. 路径带了双引号 → 服务启动 3534
  3. 日志目录没创建 → 服务启动 3534
  4. 环境变量残留 5.7 路径 → 初始化报错找 5.7 文件
  5. 端口被占用 → 服务启动 3534
  6. 杀毒软件拦截 InnoDB → 初始化卡死
  7. 临时密码没保存 → 只能重新初始化
  8. SQLyog 不支持新认证插件 → 报 2058 错误
  9. 用户 host 不匹配 → 报 1396 错误
  10. 密码不符合策略 → 报密码太简单

一句话口诀

编码 ANSI 路径对，端口独立服务名，初始化后记密码，远程授权加插件。
