欢迎来到「拾遗录」。

这里是一名 Java 开发者的技术笔记。取名「拾遗」，是因为日常踩过的坑、读过的源码、想通的问题，若不及时记下来，很快就会散落无踪。把它们收拢成文，既是给自己留档，也希望能帮到有同样困惑的人。

1. 站点定位

不追热点，不写通稿，只记录真正动手验证过的东西。每篇文章尽量做到：

  • 讲清原理：不停留在「怎么用」，尽量说清「为什么这样设计」
  • 给出实证：关键结论配可运行的代码或命令，而非道听途说
  • 标注边界：写清结论成立的前提与版本，避免以偏概全

内容以 Java 后端为主，也会涉及日常开发中的部署、运维与工具链问题。

2. 内容组织

文章通过分类与标签两个维度组织：

维度 特点 用途
分类 树形结构，一篇文章归属一个分类 按知识体系浏览
标签 扁平结构，一篇文章可有多个标签 按关键词检索

目前已有的内容方向：

  • Java 核心 —— JVM（内存结构、垃圾回收、调优工具）、Java 基础
  • 部署运维 —— Hexo 博客搭建、Cloudflare 图床、私有云与内网穿透

完整的分类规划见站点的分类页，全部标签见标签页。

3. 阅读入口

  • 想按知识体系系统学习，从分类进入
  • 想找某个具体主题，用右上角的搜索或标签筛选
  • 想了解站点的搭建过程，见「部署运维」分类下的相关文章

4. 关于作者

一名 Java 后端开发者，关注 JVM、并发编程、分布式架构与工程实践。

如果文章中有错误或表述不清的地方，欢迎通过站点底部的联系方式指出——技术上的讨论与指正，是这里持续更新的动力。
