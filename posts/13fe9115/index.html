一、服务器端自动化部署（Termux Ubuntu）

1.1 脚本整体功能

适用于 Termux proot-distro Ubuntu 环境，全自动流程：

  1. DNS 异常自动修复
  2. Gitee 私有仓库 pull / clone 源码
  3. 智能判断依赖变更，不每次重复安装依赖
  4. 保留 hexo clean && hexo generate 完整编译
  5. 强制校验编译结果，杜绝空目录报错
  6. 安全同步 public 静态文件到 Nginx 站点目录
  7. 智能 Nginx 管理：运行则重载、未运行则启动

1.2 本次解决的核心报错（重点）

报错：

根本原因：

hexo clean 会清空 public 目录，如果 hexo generate 编译异常/警告中断，public 为空，* 通配符匹配失败直接报错。

最终两套防护方案：

  1. 编译后强制校验 public/index.html，不存在直接终止脚本
  2. 复制命令由 public/* 改为 public/.，空目录也不会报错

1.3 依赖优化机制（关键改进）

不再无脑 pnpm install，采用 md5 哈希对比：

  • 监控文件：package.json、pnpm-lock.yaml

  • 文件无变化 → 跳过安装，速度极快

  • 文件变更（插件新增/升级/版本变动）→ 自动执行 pnpm install

  • 首次运行 → 自动安装依赖

  • 缓存文件：zzcblog-source/.pkg.md5sum

  • 手动强制重装依赖：rm .pkg.md5sum 再运行脚本

1.4 Nginx 智能启停逻辑

  • 检测到 Nginx 正在运行 → nginx -s reload 平滑重载
  • Nginx 未运行 → nginx -c /etc/nginx/nginx.conf 2>/dev/null 静默启动

1.5 已关闭功能

  • 关闭 Git 自动安装（环境预装 Git）
  • 关闭强制 pnpm install，改为按需检测
