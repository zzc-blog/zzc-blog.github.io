实用工具UTILITIES
100 100tools 聚合型在线工具箱，涵盖文本、图片、编码转换等常用小工具
是占位标记，由 scripts/tools-page.js 
 在渲染阶段替换成按 group 分组的卡片区块 —— 请勿删除。

 tools.yml 每条支持：
   name  工具名称（必填）
   url   完整外链（必填，http/https）
   desc  一句话说明（页面上显示；导航栏下拉不显示）
   icon  图标方块里的 1~3 个字符，留空取名称首字
   group 分组名（页面上分组；导航栏下拉不分组、按顺序列出）
